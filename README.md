# BroadcastHub

Fullstack SaaS application for managing contacts and sending broadcast messages.

## 🚀 Tech Stack

* Backend: Node.js, Express
* Frontend: React (Vite + TypeScript)
* Version Control: Git

---

## 📦 Project Structure

```
broadcast-hub/
  backend/
  frontend/
```

---

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone git@github.com:sergiowelter/broadcast-hub.git
cd broadcast-hub
```

Or using HTTPS:

```bash
git clone https://github.com/sergiowelter/broadcast-hub.git
cd broadcast-hub
```

### Configure SSH (Optional but recommended)

If you cloned via HTTPS and want to use SSH:

```bash
git remote set-url origin git@github.com:sergiowelter/broadcast-hub.git
```

Verify the remote configuration:

```bash
git remote -v
```

---

### 2. Run the backend

```bash
cd backend
npm install
npm run dev
```

---

### 3. Run the frontend

```bash
cd frontend
npm install
npm run dev
```
