# Broadcast Hub

Um projeto full-stack para gerenciamento de transmissões ao vivo.

## Estrutura do Projeto

- `backend/` - API backend em Node.js/TypeScript
- `frontend/` - Aplicação frontend em React

## Como executar

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm start
```

## Tecnologias

- Backend: Node.js, Express, TypeScript
- Frontend: React, TypeScript
