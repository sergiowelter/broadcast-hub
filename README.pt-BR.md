# BroadcastHub

Aplicação fullstack SaaS para gerenciar contatos e enviar mensagens em broadcast.

🇺🇸 [Read in English](README.md)

## 🚀 Pilha Tecnológica

* Backend: Node.js, Express
* Frontend: React (Vite + TypeScript)
* Controle de Versão: Git

---

## 📦 Estrutura do Projeto

```
broadcast-hub/
  backend/
  frontend/
```

---

## 🧠 Arquitetura

Este projeto segue as melhores práticas de engenharia de software, incluindo:

* Princípios SOLID
* Arquitetura em camadas
* Separação de responsabilidades
* Estrutura modular

### Camadas do backend

* **Rotas** → definem os endpoints da API
* **Controladores** → lidam com requisições e respostas HTTP
* **Serviços** → contêm a lógica de negócio
* **Repositórios** → lidam com o acesso a dados

## ⚙️ Começando

### 1. Clonar o repositório

```bash
git clone git@github.com:sergiowelter/broadcast-hub.git
cd broadcast-hub
```

Ou usando HTTPS:

```bash
git clone https://github.com/sergiowelter/broadcast-hub.git
cd broadcast-hub
```

### Configurar SSH (Opcional, mas recomendado)

Se você clonou via HTTPS e quer usar SSH:

```bash
git remote set-url origin git@github.com:sergiowelter/broadcast-hub.git
```

Verifique a configuração do remote:

```bash
git remote -v
```

---

### 2. Executar o backend

```bash
cd backend
npm install
npm run dev
```

---

### 3. Executar o frontend

```bash
cd frontend
npm install
npm run dev
```
